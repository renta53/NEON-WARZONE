Python（Pygame）で開発した近未来型サバイバルシューティングゲーム。

敵を倒して経験値を獲得し、レベルアップや武器変更を行いながら、押し寄せる敵のウェーブを生き残る2Dアクションゲームです。

## 🎮 ゲーム概要

プレイヤーは近未来都市を舞台に、次々と出現する敵と戦います。

敵を倒すことでスコアや経験値を獲得し、レベルアップしながらより強力な敵に立ち向かいます。

## ✨ 主な機能

- 近未来都市を舞台にした2Dシューティング
- プレイヤーの移動・射撃
- 複数の武器を切り替えて戦闘
- 敵キャラクターごとの異なる性能
- 敵AIによるプレイヤーへの追跡
- HP・アーマーシステム
- 経験値・レベルアップシステム
- ウェーブ制バトル
- ダメージ・撃破エフェクト
- パーティクルエフェクト
- ミニマップ
- カメラ追従・画面揺れ
- ゲームオーバー・リスタート機能

## 🎮 操作方法

| 操作 | キー |
|---|---|
| 移動 | W / A / S / D |
| 射撃 | 左クリック |
| リロード | R |
| 武器変更 | 1 / 2 / 3 |
| ポーズ | ESC |
| スタート・リスタート | ENTER |
